# Wrapper around aNCA::l_pkcl01() for TAD-based concentration listings.

Wrapper around aNCA::l_pkcl01() for TAD-based concentration listings.

## Usage

``` r
l_pkcl01_tad(data, ...)
```

## Arguments

- data:

  Data to be passed into the listing function.

- ...:

  Any other parameters to be passed into the listing function.

## Value

A named list of listing_df objects.
