# Wrapper around aNCA::pkcg01() function. Calls the function with `SBS` scale argument.

Wrapper around aNCA::pkcg01() function. Calls the function with `SBS`
scale argument.

## Usage

``` r
g_pkcg01_sbs(data, ...)
```

## Arguments

- data:

  Data to be passed into the plotting function.

- ...:

  Any other parameters to be passed into the plotting function.

## Value

ggplot2 object for pkcg01.
